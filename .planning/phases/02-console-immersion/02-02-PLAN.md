Create `src/hooks/useViewCount.js`, default export `useViewCount(code, path)`, matching the `useTheme.js` style. State starts as `null`. In `useEffect` keyed on `[code, path]`: return immediately if `code` is falsy — this early return is what keeps the unconfigured site from firing a DNS lookup at a nonexistent subdomain on every page load. Otherwise create an `AbortController`, `fetch` the URL `https://` + code + `.goatcounter.com/counter/` + `encodeURIComponent(path)` + `.json` with its `signal`, reject non-`ok` responses, parse JSON, and set state to `String(data.count)` only when `data.count` is a string or number — anything else sets `null`. Attach a `.catch` that sets `null`, so an ad-blocked request, a 403 from a site with the public counter setting disabled, or a schema change all resolve to "hidden", never to an unhandled rejection or a stuck loading state. Return a cleanup that aborts the controller.

Render the count as a plain React text child so React's default escaping applies. Do not build the element's markup from the response string and do not use any raw-HTML injection prop.

In `src/components/Footer.jsx`, import `analytics` and the hook, call `const views = useViewCount(analytics.goatCounterCode, analytics.countPath)`, and render — only when `views` is truthy — a `<p className="queue-tag queue-tag--views">` containing the label `VIEWS:` and `<span className="queue-tag__count">{views}</span>`, as a sibling of the existing copyright paragraph.
