| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-02-11 | Information Disclosure | enabling public visitor counts | low | accept | The exposed datum is an aggregate page-view number the site owner is deliberately publishing. The GoatCounter public-counter switch exposes only totals, no per-visitor data. |
| T-02-SC | Tampering | npm/pip/cargo installs | high | mitigate | No package installs occur in this plan or anywhere in Phase 2; runtime dependencies remain react + react-dom, asserted by the plan 02-02 gate. Package Legitimacy Gate is N/A (no install tasks). |
